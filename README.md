# Sistema IEC — Distribuição

Repositório **público** de distribuição do **Sistema IEC**.

O código-fonte fica no repositório privado (`sistema-iec`); este repositório
recebe apenas as **Releases** (binários) a cada nova versão, publicadas
automaticamente pela CI do repositório de código.

## Baixar

- **Windows:** `SistemaIEC-windows.exe` da release mais recente.
- **Linux:** `SistemaIEC-linux` da release mais recente.

O programa também se atualiza sozinho: ele consulta a última release deste
repositório de forma **anônima** — nenhum login, token ou autorização é
necessário em nenhuma máquina.
